북마크 정리 도구

브라우저 북마크 파일에서 불필요한 아이콘 데이터를 제거하고, AI 챗봇에 붙여넣을 수 있는 텍스트로 변환한다.

이용 전 참고사항
• AI가 북마크를 자동 분류하므로, 결과가 기대와 다를 수 있다. 변환 후 폴더 구조를 반드시 확인한다.
• 대량의 북마크를 처리하는 과정에서 일부 항목이 누락될 수 있다. 변환 후 누락 검증 기능으로 확인하고 보완한다.

① 북마크 파일 불러오기

북마크 내보내기 방법
• Chrome / Edge: 북마크 관리자(Ctrl+Shift+O) → 우상단 ⋮ 메뉴 → 북마크 내보내기
• Firefox: 북마크 라이브러리(Ctrl+Shift+B) → 가져오기 및 백업 → HTML로 내보내기
• Safari: 파일 메뉴 → 북마크 내보내기

정리 방식 선택
⚙️
구조 최적화 안정적
기존 폴더 구조를 AI에게 전달하여, 현재 분류를 유지하면서 개선점만 반영한다.
기존 분류가 어느 정도 잘 되어 있고, 미세 조정이 필요할 때 적합하다. 이미 익숙한 구조를 크게 바꾸지 않으므로 결과를 바로 적용하기 쉽다.
✨
제로베이스 재분류 과감한
폴더 정보를 모두 제거하고 북마크만 전달하여, AI가 처음부터 최적의 구조를 설계한다.
기존 분류가 뒤죽박죽이거나, 완전히 새로운 관점의 정리가 필요할 때 적합하다. 기존 구조에 대한 편향 없이 순수하게 콘텐츠 기반으로 분류한다.
추가 요구사항 (선택)

AI에게 전달할 추가 조건을 자유롭게 작성한다. 입력한 내용이 아래 프롬프트에 자동 반영된다.

프롬프트 + 데이터 통합본 (아래를 그대로 복사해서 AI 채팅창에 붙여넣는다)
복사됨
중요: AI가 마크다운 형식(## 폴더명, - [제목](URL))으로 결과를 출력하면 아래 ④단계에서 북마크 HTML로 바로 변환할 수 있다. 프롬프트에 이 형식이 이미 지정되어 있다.

④ AI 결과 → 북마크 파일로 변환

북마크 내보내기 → 이 도구로 변환 → AI에 붙여넣기 → AI 결과 변환 → 브라우저 가져오기

AI 챗봇이 출력한 마크다운 텍스트를 아래에 붙여넣고 "변환" 버튼을 누른다.
## 폴더명은 폴더로, - [제목](URL)은 북마크로 변환된다.

⑤ 브라우저에 북마크 가져오기

북마크 내보내기 → 이 도구로 변환 → AI에 붙여넣기 → AI 결과 변환 → 브라우저 가져오기
가져오기 전 주의사항: 기존 북마크에 새 구조가 추가되는 방식이다. 기존 북마크를 먼저 백업(내보내기)한 뒤 삭제하고 가져오면 깔끔하게 교체된다.
  • 1 Chrome / Edge: 북마크 관리자(Ctrl+Shift+O) → 우상단 ⋮ 메뉴 → 북마크 가져오기 → 다운로드한 HTML 파일 선택
  • 2 Firefox: 북마크 라이브러리(Ctrl+Shift+B) → 가져오기 및 백업 → HTML에서 북마크 가져오기 → 파일 선택
  • 3 Safari: 파일 메뉴 → 다음에서 가져오기 → 북마크 HTML 파일 → 파일 선택
