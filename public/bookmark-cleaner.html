북마크 정리 도구

브라우저 북마크 파일에서 불필요한 아이콘 데이터를 제거하고, AI 챗봇에 붙여넣을 수 있는 텍스트로 변환해 드려요. 약 10~15분이면 끝나요.

→ → → → →
기존 북마크는 그대로 유지돼요.
이 도구는 북마크를 복사본으로 내보내서 정리하는 방식이에요. 원래 브라우저의 북마크에는 아무 영향이 없으니 안심하세요.
이용 전 참고사항
• AI가 북마크를 자동 분류하기 때문에, 결과가 기대와 다를 수 있어요. 직접 수행변환 후 폴더 구조를 꼭 확인해 주세요.
• 대량의 북마크를 처리하는 과정에서 일부 항목이 누락될 수 있어요. 직접 수행변환 후 누락 검증 기능으로 확인하고 보완해 주세요.

⓪ 북마크 내보내기

북마크를 정리하려면, 먼저 브라우저에 저장된 북마크를 파일로 꺼내야 해요.
아래에서 본인이 사용하는 브라우저를 찾아 순서대로 따라해 주세요.
완료하면 컴퓨터에 bookmarks로 시작하는 HTML 파일이 저장돼요.

  • C Chrome / Edge
    Windows: Ctrl+Shift+O → 우상단 ⋮ 메뉴 → 북마크 내보내기
    Mac: ⌘+Option+B → 우상단 ⋮ 메뉴 → 북마크 내보내기
  • F Firefox
    Windows: Ctrl+Shift+B → 가져오기 및 백업 → HTML로 내보내기
    Mac: ⌘+Shift+B → 가져오기 및 백업 → HTML로 내보내기
  • S Safari (Mac 전용)
    파일 메뉴 → 북마크 내보내기

① 파일 불러오기

방금 저장한 북마크 HTML 파일을 이 도구에 올려 주세요.
가장 쉬운 방법은 아래 "파일 선택" 버튼을 누르는 거예요.

직접 수행아래 버튼을 눌러 북마크 파일을 선택해 주세요.
📂

또는 파일을 이 영역으로 끌어다 놓을 수도 있어요.

② 변환 결과

파일이 어떻게 변환됐는지 확인하는 단계예요.
북마크에서 불필요한 데이터를 제거했어요. 직접 수정할 필요는 없으니, 확인 후 아래 ③단계로 넘어가 주세요.

변환된 데이터 보기 (직접 수정할 필요 없어요)
위 내용은 확인만 하시면 돼요. 다음 단계로 넘어가세요.

③ AI에 붙여넣기

이 단계에서는 AI 챗봇의 도움을 받아요. 아래 순서를 따라 주세요.
  1. 정리 방식을 하나 고르세요. 잘 모르겠다면 "구조 최적화"를 추천해요.
  2. "프롬프트+데이터 통합 복사" 버튼을 누르세요.
  3. AI 챗봇 사이트를 열고, 대화창에 Ctrl+V(Mac: ⌘+V)로 붙여넣은 뒤 전송하세요.
    ChatGPT 열기 ↗ Claude 열기 ↗ Gemini 열기 ↗
  4. AI의 답변이 끝나면 다음 ④단계로 넘어가세요.
    주의: 이 페이지와 AI 창을 모두 열어 두세요. 둘 다 필요해요.
정리 방식 선택
⚙️
구조 최적화 안정적
기존 폴더 구조를 AI에게 전달하여, 현재 분류를 유지하면서 개선점만 반영해요.
기존 분류가 어느 정도 잘 되어 있고, 미세 조정이 필요할 때 적합해요. 이미 익숙한 구조를 크게 바꾸지 않으므로 결과를 바로 적용하기 쉬워요.
✨
제로베이스 재분류 과감한
폴더 정보를 모두 제거하고 북마크만 전달하여, AI가 처음부터 최적의 구조를 설계해요.
기존 분류가 뒤죽박죽이거나, 완전히 새로운 관점의 정리가 필요할 때 적합해요. 기존 구조에 대한 편향 없이 순수하게 콘텐츠 기반으로 분류해요.
추가 요구사항 (선택)

직접 수행AI에게 전달할 추가 조건을 자유롭게 작성해 주세요. 입력한 내용이 아래 프롬프트에 자동으로 반영돼요.

프롬프트 + 데이터 통합본
직접 수행아래 버튼을 눌러 복사한 뒤, AI 채팅창에 그대로 붙여넣어 주세요.
복사됨
참고: AI가 마크다운 형식(## 폴더명, - [제목](URL))으로 결과를 출력하면 아래 ④단계에서 북마크 HTML로 바로 변환할 수 있어요. 프롬프트에 이 형식이 이미 지정되어 있으니 걱정하지 않으셔도 돼요.
생성된 프롬프트 미리보기

④ AI 결과 변환

AI 챗봇 화면으로 돌아가세요.
  1. AI가 출력한 답변 전체를 복사하세요. (답변 옆 복사 버튼 또는 드래그 후 Ctrl+C)
  2. 이 페이지로 돌아와서 아래 입력칸에 Ctrl+V로 붙여넣으세요.
  3. "북마크 HTML로 변환" 버튼을 누르세요.
  4. 변환이 끝나면 "북마크 HTML 다운로드" 버튼을 눌러 파일을 저장하세요.
잘 안 되나요?
  • AI의 답변이 완전히 끝날 때까지 기다린 후 복사해 주세요.
  • 결과가 이상하다면 AI에서 새 채팅을 열고 ③단계부터 다시 시도해 보세요.
  • 복사할 때는 AI 답변 옆의 복사 버튼을 이용하면 편해요.

직접 수행변환이 완료되면 아래 버튼을 눌러 북마크 HTML 파일을 다운로드해 주세요.

혹시 빠진 북마크가 있다면 여기에 표시돼요.
"누락 목록 복사" 버튼을 누르고, AI 챗봇에 다시 붙여넣으면 빠진 항목을 보완해 줘요.
빠진 항목이 없다면 이 부분은 무시하고 ⑤단계로 넘어가세요.

복사됨

⑤ 브라우저 가져오기

마지막 단계예요. ④에서 다운로드한 파일을 브라우저에 넣으면 정리 끝이에요.
아래에서 본인 브라우저를 찾아 순서대로 따라해 주세요.

  • C Chrome / Edge
    Windows: Ctrl+Shift+O → 우상단 ⋮ 메뉴 → 북마크 가져오기 → HTML 파일 선택
    Mac: ⌘+Option+B → 우상단 ⋮ 메뉴 → 북마크 가져오기 → HTML 파일 선택
  • F Firefox
    Windows: Ctrl+Shift+B → 가져오기 및 백업 → HTML에서 북마크 가져오기 → 파일 선택
    Mac: ⌘+Shift+B → 가져오기 및 백업 → HTML에서 북마크 가져오기 → 파일 선택
  • S Safari (Mac 전용)
    파일 메뉴 → 다음에서 가져오기 → 북마크 HTML 파일 → 파일 선택
